# kelseydoubleu.github.io/portfolio

Portfolio site for Kelsey Wang.

- `index.html`, `about.html`, `work/*.html` are generated. Edit `_src/content.py`, then run `python3 _src/build.py` from the repo root (needs Pillow for image sizes, optional).
- `img/` holds the web images (JPG, max 2000px).
- `book/` is the flipbook PDF viewer (`book/portfoliofile.pdf`).
